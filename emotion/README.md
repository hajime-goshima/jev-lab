# emotion — 問い合わせの感情分析

[TypeSafe AI](https://docs.typesafe.ai/) の System One モデル **Jev** で、顧客からの問い合わせを感情分析してみた実験です。

日本語の問い合わせ1000件（想定の感情ラベル付き）を用意し、1件ごとに次の6問を1回のリクエストでまとめて聞いています。

| キー | 型 | 内容 |
|---|---|---|
| `sentiment` | Choice | positive / neutral / negative / mixed |
| `emotion` | Choice | 感謝・喜び・怒り・苛立ち・失望・不安・なし |
| `anger` | Score (0〜3) | 怒りの強さ |
| `urgent` | Noul | 緊急度 |
| `churn_risk` | Noul | 解約リスク |
| `sarcasm` | Noul | 皮肉かどうか |

## 実行方法

Ruby 3.4 の標準ライブラリだけで動きます（gem不要）。

```bash
cp .env.example .env   # TYPESAFE_API_KEY を設定

ruby demo.rb                       # ランダムに10件を1件ずつ判定して、所要時間を表示
ruby demo.rb 20                    # 件数を指定
ruby demo.rb "返金はいつですか？"     # 好きな文を判定
ruby analyze.rb                    # 1000件を10並列で一括判定して集計
```

`demo.rb` の出力例:

```
「もう3回目の問い合わせです。いつ返金されるんですか？解約も考えています。」(36字)
  😠 negative (確信度 1.0)  感情:frustration  怒り:2.9/3  ⚑ urgent churn_risk
  ⏱  229 ms
```

## データセット

- 1000件（positive 205 / neutral 223 / negative 377 / mixed 195）
- #1〜100 は短文中心の汎用セット。#101〜1000 は9業界×100件（EC、SaaS、通信、金融、旅行、飲食、メーカー修理、教育・ジム、不動産・インフラ・医療）
- 平均243字、最大1361字。800字以上の長文メールやチャットログ、過去のやり取りの引用、英語混じり、高齢者の文、皮肉・慇懃無礼・遠回しな不満を含む
- 判定が難しい文（`tricky: true`）は225件

## 結果（jev-1.13.0）

以下は最初にPython版で1000件を実行したときの結果です（`results/` に保存済み）。

| 項目 | 結果 |
|---|---|
| 感情ラベル正解率 | **958/1000 (95.8%)** |
| 普通の文 | 761/775 (98.2%) |
| 難しい文 | 197/225 (87.6%) |
| 1000件の処理時間（同時10並列） | 22.4秒 |
| 1件あたりの応答時間 | 中央値 0.21秒 / 最大 0.70秒 |
| 入力トークン合計 | 約93万 |

**文字数帯別**

| 文字数 | 正解率 |
|---|---|
| 〜99字 | 98.6% |
| 100〜299字 | 95.0% |
| 300〜799字 | 95.2% |
| 800字〜 | 89.1% |

**特徴別**（抜粋）: 口語・誤字・絵文字は100%、皮肉 95.7%、慇懃無礼 90.9%、**遠回しな不満 74.3%**（いちばん苦手）

### 誤りの傾向

42件の誤りのうち26件が「想定 negative → 予測 mixed」でした。中身を見ると、「長年使ってきて愛着はあるが、最近電波が悪い」「店員は丁寧だったが、請求額が高い」のように、ポジティブな要素も実際に書かれている文が多く、ラベル自体が割れうるものです。次に多いのは「想定 neutral → 予測 positive」の8件で、ビジネスメールの「先日はご回答ありがとうございました」のような定型の感謝に引っ張られていました。

### 確信度で人の確認に回す

| 運用 | 人が確認する件数 | 捕捉できる誤り | 自動処理分の正解率 |
|---|---|---|---|
| 確信度 < 0.8 を人へ | 82件 (8.2%) | 42件中30件 | 906/918 (98.7%) |
| 確信度 < 0.95 を人へ | 172件 (17.2%) | 42件中39件 | 825/828 (99.6%) |

確信度0.95以上の828件は、99.6%が正解でした。

## 注意

問い合わせ文と想定ラベルはどちらも AI（Claude）が作ったものです。実際の問い合わせより文が整っていてラベルも明確なので、この正解率は実力より高めに出ている可能性があります。また上のとおり、誤りとされた中にはラベル側が議論の余地のあるものも含まれています。

## ファイル構成

- `data/inquiries.jsonl` — 問い合わせ1000件と想定ラベル（`domain` 業界、`traits` 文の特徴、`tricky: true` は難しい文）
- `jev.rb` — Jev APIを呼ぶ小さなクライアントと、6つの質問の定義
- `demo.rb` — 1件ずつ判定して速さを見るデモ
- `analyze.rb` — 1000件の一括判定と集計
- `results/results.jsonl` — 分析結果（全件）
- `results/errors.jsonl` — 不正解だった42件
