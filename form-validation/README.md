# form-validation — 問い合わせフォームのリアルタイム検証

ブラウザの問い合わせフォームで、入力が止まって0.3秒後にフォーム全体を [TypeSafe AI](https://docs.typesafe.ai/) の **Jev** に渡し、中身を判定します。
正規表現では書けない「これは営業メールか」「内容が足りているか」「カード番号を書いていないか」を、入力しながら約0.2〜0.3秒で返します。

## 実行方法

Ruby 3.4 と、`rack` / `rackup` / `puma` の gem を使います。

```bash
cp .env.example .env   # TYPESAFE_API_KEY を設定
ruby server.rb         # → http://localhost:4567 をブラウザで開く
```

画面上部の「例文」ボタンを押すと、用意した文が入って判定されます。

| 例文 | 判定されること |
|---|---|
| 普通の問い合わせ | ✓ 送信できます |
| 営業メール | 営業・宣伝（営業窓口へ回す） |
| 怒り | 攻撃的な表現、内容が不足 |
| カード番号入り | カード番号・パスワード等 → **送信ボタンが押せなくなる** |
| 内容不足 | 名前が「test」、メール形式の誤り、内容が不足 |
| 件名ずれ | 件名が本文と合っていない |

## 構成

```
ブラウザ (index.html の JS)  ──POST /jev──▶  server.rb  ──▶  Jev API
  質問の定義・結果の使い方                   そのまま中継するだけ
                                             APIキーはここにだけ置く
```

- Jev API はブラウザからの直接呼び出し（CORS）を許可していないため、`server.rb` で中継しています。そのおかげで APIキーもブラウザに出ません
- 何を聞くか（質問の定義）と、結果をどう使うか（警告・送信ブロック）は、すべて `index.html` の JS 側にあります
- 質問は入力がある欄の分だけ送ります（空の件名について聞いても意味がないため）。多いときは6問を1回で聞きます
- メールアドレスの形式は正規表現で十分なので、Jev には聞かずにJSで判定しています（画面にも「コードで判定」と表示）

## Jev に聞いている質問

フォーム全体を `{ name, email, subject, message }` の JSON のまま `state` として渡します。

| キー | 型 | 内容 | 使い方 |
|---|---|---|---|
| `name_ok` | Noul | 名前らしいか（test、でたらめな文字、文章ではないか） | 0.5未満なら注意 |
| `kind` | Choice | inquiry / sales / spam / prank | spam・prank は送信不可、sales は注意 |
| `abusive` | Noul | 攻撃的な表現・脅しがあるか | 注意 |
| `secret` | Noul | カード番号・パスワードなどを書いていないか | **送信不可** |
| `vague` | Noul | 内容を理解するだけで聞き返しが必要か | 本物の問い合わせのときだけ注意 |
| `subject_match` | Noul | 件名が本文と合っているか | 注意 |

`vague` は最初「内容が十分か（detail）」と聞いていましたが、具体的な文でも0.3〜0.4になり「内容不足」と出てしまいました。「聞き返さないと何の話か分からないか」と逆向きに聞くと、例文6つがきれいに分かれました（内容不足の例文 0.90、それ以外 0.08〜0.21、怒りの例文 0.74）。

## 速さ

- ブラウザで測った往復の時間は、1回あたり約210〜360ms。そのうち Jev の処理がほとんどで、中継の分は数ms
- 画面には「ブラウザでの往復時間」と「うち Jev の時間」（`server.rb` が `x-jev-ms` ヘッダーで返す）を並べて出しています

速さのために2つ工夫しています。

- `server.rb` は起動時に Jev への接続を3本張って使い回します。1回目のリクエストだけTLS接続の待ちで約0.8秒かかるのを防ぐためです
- `jev.rb` は接続を保つ時間を120秒に延ばしています。Ruby の `Net::HTTP` は既定では2秒使わないと接続を張り直すため、入力に間があくたびに約0.4秒余計にかかっていました（5秒あけると約760ms → 延ばすと約350ms）

## ファイル構成

- `server.rb` — 画面の配信と Jev への中継（約40行）
- `index.html` — フォーム、質問の定義、判定結果の表示
- `jev.rb` — Jev API を呼ぶ小さなクライアント（他の実践と同じもの）
